What to do if you get this:

Warning: Pub installs executables into C:\Users\{user}\AppData\Local\Pub\Cache\bin, which is not on your path.
You can fix that by adding that directory to your system's "Path" environment variable.
A web search for "configure windows path" will show you how.


    Windows key -> Type in: PATH -> Edit the System Environment Variables -> Environment Variables -> System Variables -> 'Path' click on it then click edit -> New -> Paste in the path you got in your error message -> Ok Ok Ok -> Restart VS Code
